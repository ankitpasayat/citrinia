## The pipeline
1. **Persona bibles**: `seed/personas/batch-01.md … batch-50.md`, `manifest.json`.
2. **Media pool**: `seed/media-pool.json` (506 verified items), queried with `node seed/pool.mjs --tags a,b [--kind gif|image|youtube] [--limit 8] [--any]`. Verified URLs are cached in `seed/.urlcache.json` (gitignored; regenerate with `node seed/validate.mjs --check-pool seed/media-pool.json`, ~8 min cold).
3. **Bulk writing** (done for 01–50; keep for any future batch): one Sonnet 5 agent per batch, prompt below, following `seed/docs/SEED-BULK.md` (+ `seed/docs/SEED-BRIEF.md`). Output `seed/content/bulk-NN.json`. Haiku was rejected (fragments, off-topic replies). Run ~8 agents at a time; each takes 30–55 min and ~300k tokens.
4. **Validation**: `node seed/validate.mjs` (whole set) and `node seed/validate.mjs --check-urls seed/content/<file>` (format, media, quality gates). Quarantine failures in `seed/rejected/`; never edit accepted files by hand without re-validating.
5. **QA before accepting** (the gates catch slop, not these): `node seed/qa.mjs seed/content/bulk-NN.json` prints the length rhythm, five random peels, three reply pairs and a wiring scan. Read them. What came up in batches 17–48 and how it was handled:
   - **All essays** (0–2% of peels under 100 chars, average 200+): send the same agent back (SendMessage) to *add* ~70 real quick takes (jokes, one-line reactions, questions) in each persona's voice; the validator's 15%-under-80 ceiling caps how many. Never accept "shortened by truncation": batch 37 did that and produced setups with the payoff cut off; the fix was restoring the full drafts and adding genuine quick takes.
   - **Off-by-one reply wiring**: a reply whose text plainly echoes peel N±1 or N±2. The scan flags candidates; many flags are fine (thread closers, two peels from the same seed), so read each. Real ones: rewire `to`, and lower `age_hours` below the new parent's if needed. Batch 38 had 19 of these (index keying bug in the writer's script); most batches had 0–2.
   - **Short counts**: replies < 200 or quotes < 40 are not gated; ask the agent to top up (batches 32, 42, 43) rather than accept thin batches.
   - **Duplicates**: one reply that restated an existing peel nearly verbatim was dropped (batch 46).
   - **Persona tics that look like artifacts** (bracketed "[Translation of …]" peels in batch 27, lowercase unpunctuated one-liners in batch 41) are specified in the persona bible; check `seed/personas/batch-NN.md` before "fixing" them.
   - Agents share one scratchpad directory and have overwritten each other's build scripts; the prompt now tells them to use a per-batch subdirectory.
6. **Import**: `node seed/seed.mjs --target live` backfills everything (pauses notification triggers, backdates) — DO NOT run this again for bulk batches; use drip. `node seed/seed.mjs --target live --drip 135` publishes the next slice as if it happened in the last hour. Self-test: `node seed/seed.test.mjs`.
7. **Drip schedule**: `.github/workflows/drip.yml`, hourly at :07 (first scheduled run fired 12:34 IST on 2026-09-06, see above). Content files must be committed and pushed for the workflow to see them; the drip skips anything already on production.

## Relaunch prompt for a bulk batch (Sonnet 5, background agent)
> You are writing bulk seed content for Citrinia. Your batch is **NN**. Working directory: /home/ankit/Code/citrinia. Read `seed/docs/SEED-BULK.md` first and follow it exactly (it points you to `seed/docs/SEED-BRIEF.md` and the anchor files too; read those as instructed). Specifics: persona file `seed/personas/batch-NN.md`; output `seed/content/bulk-NN.draft` (`"cluster": "bulk-NN"`, ids `bulk-NN-001`… / `bulk-NN-r001`…), validated with `node seed/validate.mjs --check-urls seed/content/bulk-NN.draft` until it prints OK, then `mv` it to `seed/content/bulk-NN.json` and run `node seed/validate.mjs` once more (whole set must be OK). Media only from `node seed/pool.mjs` output, pasted exactly as printed. Keep the length rhythm the spec asks for: average around 165 characters with roughly 15% quick takes under 100 characters, not all essays; write the quick takes as quick takes (a joke, a reaction, a one-line question), never by mechanically truncating longer drafts. If you use scratch files, put them in a subdirectory named `seedNN/` under your scratchpad directory, because other writers share that directory and have overwritten each other's files. If you generate the file with a script, double-check every reply's `to` id by printing each reply next to its parent's text and reading them together; a previous batch had replies pointed at the neighbouring peel id by an off-by-one. Touch no other file; do not run git; do not start servers. Report the validator summary line for your batch and three favourite peels.

After acceptance: `git add seed/content/bulk-NN.json && git commit -m "Seed content: bulk batch NN" && git push` (pushes from the owner's machine have taken 2–6 minutes; run them in the background with a long timeout).

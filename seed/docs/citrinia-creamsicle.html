Creamsicle · the Citrinia design language

Soft as sorbet, loud as a seventies sunset.

Sorbet's borderless, rounded, phone-first structure with Tangerine Dream poured over it. Four stripes are the brand mark, Shrikhand does the shouting, everything you can press has a lip you sink onto, and nothing has an outline.

This is the build spec. Every value maps to a token in tokens.stylex.ts at the bottom. Toggle the theme above to check dark.

Stripes are the logo

Burnt, amber, mustard, cream, always in that order, always horizontal. They never change with the theme. The band, the sheet handle and the login slab are the only places they appear.

Lips, not outlines

Nothing has a border. Surfaces are tonal and float on a soft shadow. Pressable things have a 4px lip underneath; pressing sinks the button onto it, so feedback is physical without a color change.

One column, thumbs first

Phone is the source layout: edge to edge, tabs at the bottom, compose in a sheet. Tablet and desktop get the same column widened and centered on peach. The same CSS ships to the web, a PWA and a Capacitor shell.

Color

Peach by day, cocoa by night

Dark mode is system preference only. The stripes, amber, mustard and the button gradient are constant; ground, surfaces, ink and the chip tint swap. Burnt orange lightens one step in dark so Shrikhand names still clear 4.5:1 on the cocoa surface.

Typography

Shrikhand shouts, Nunito talks

Shrikhand is one fat italic weight, used for the wordmark, author names, sheet titles, the empty state and any big number. Nunito 600 to 800 carries everything else; its rounded terminals match. Both are self-hosted woff2 in public/fonts because StyleX's Babel config disables next/font. Counters and timestamps use tabular digits.

Breakpoints
Under 600px: column is the viewport, 16px gutters. 600px and up: column 520px centered, 24px gutters. There is no third layout; desktop is tablet with more peach.
Safe areas
Viewport meta uses viewport-fit=cover. Band top padding and tab bar bottom offset add env(safe-area-inset-top/bottom), so notches and home indicators never cover them in a PWA or Capacitor WebView.
Heights
100dvh, never 100vh, so the sheet and empty states size correctly when mobile browser chrome collapses.
Touch
Every target is at least 44px. Hover effects are wrapped in @media (hover: hover) so they do not stick on touch. Buttons set touch-action: manipulation and no tap highlight. The sheet uses overscroll-behavior: contain.
Type and spacing
Font sizes in rem, spacing in px, so a user's larger-text setting scales the words and not the layout.
PWA
app/manifest.ts with name, standalone display, theme color burnt, background peach, the existing SVG icon. theme-color meta for both schemes. Installable from day one; a service worker is not in this MVP.
Capacitor
The app uses server components and server actions, so a Capacitor shell points at the hosted URL (server.url in the Capacitor config) rather than a static bundle. The CSS needs nothing extra for that.

Motion

Four moves

Sink
Press moves a button down 4px and removes its lip. 90ms ease. Hover brightens 7%.
Pop
Wedge scales 0.7 to 1.25 to 1 with a small wobble, 320ms overshoot curve, only when liking.
Sheet
Slides up 200ms ease-out; backdrop fades in. Closes on Cancel, Escape, backdrop tap, or successful post.
Ambient
Live dot pulses at 2s. Skeleton shimmers at 1.4s.
Reduced motion
All of the above are disabled. Sink still applies instantly so pressing stays tactile.
